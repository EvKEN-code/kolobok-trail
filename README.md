# Тропинка Колобка

Развивающая 3D-игра в браузере для детей 5–6 лет. Колобок идёт по солнечному лесу к бабушке, по пути встречает десять сказочных героев, и каждый даёт по пять заданий.

## Что внутри

- 10 локаций и 50 заданий: счёт, сложение и вычитание, буквы и слоги, память, логика, цвета и фигуры.
- Герои: Заяц, Волк, Медведь, Лиса, Баба-яга, Лягушка, Ёжик, Сова, Петушок, Мышка. У новых пяти свои декорации: пруд, грибная поляна, старый дуб, двор, теремок.
- Задания читаются вслух голосом браузера, есть кнопка «Послушать».
- Спокойная фоновая музыка, собранная прямо в браузере. Музыку и звук можно выключить отдельно.
- За верный ответ с первой попытки даётся звезда. Звёзды сохраняются в браузере.
- Работает на компьютере и на телефоне.

## Как запустить

Откройте `index.html` в браузере. Нужен интернет: 3D-библиотека [three.js](https://threejs.org/) (r128) и шрифты подгружаются из сети.

## Как опубликовать на GitHub Pages

В репозитории: Settings, Pages, Source: Deploy from a branch, ветка `main`, папка `/ (root)`.

## Технологии

Один файл `index.html`: HTML, CSS и JavaScript без сборки. 3D на three.js, звук через Web Audio API, озвучка через Web Speech API.
